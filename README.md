# Landing Page — تعمیرات فر و گاز

Landing page تک‌صفحه‌ای فارسی/RTL با Next.js + TypeScript + Material UI.

## اجرا

```bash
npm install
npm run dev
```

سپس:
http://localhost:3000

## ساختار

- `app/` — App Router, theme, global styles
- `components/` — بخش‌های صفحه
- `theme.ts` — Material UI theme و RTL
- `public/` — دارایی‌های استاتیک

تصاویر نمونه از Unsplash به صورت remote استفاده شده‌اند؛ برای production بهتر است تصاویر واقعی کسب‌وکار داخل `public/images` قرار بگیرند.
